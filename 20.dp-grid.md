# CASE 1: Count Paths

## 1. Unique Paths
[Leetcode link](https://leetcode.com/problems/unique-paths/description/)

There is a robot on an m x n grid. The robot is initially located at the top-left corner (i.e., grid[0][0]).
 The robot tries to move to the bottom-right corner (i.e., grid[m - 1][n - 1]). The robot can only 
 move either down or right at any point in time.

Given the two integers m and n, return the number of possible unique paths that the robot can 
take to reach the bottom-right corner.

### Intuition
> [!IMPORTANT]
> To reach at (i, j), we can either come from:
>
>               1. (i-1, j)
>               2. (i, j-1)
>
> State:
>
>               dp[i][j] = number of ways to arrive at (i, j)
>
> Transition:
>
>               dp[i][j] = dp[i-1][j] + dp[i][j-1]

```cpp
int uniquePaths(int m, int n) {
    swap(n, m);
    vector<vector<int>> dp(n, vector<int>(m, 0));
    dp[0][0] = 1;

    for(int i=0; i<n; i++) {
        for(int j=0; j<m; j++) {
            if(i == 0 && j == 0) continue;

            if(i > 0) dp[i][j] += dp[i-1][j];
            if(j > 0) dp[i][j] += dp[i][j-1];
        }
    }

    return dp[n-1][m-1];
}
```

# CASE 2: Minimum Cost Path

## 1. Minimum Path Sum
[Leetcode link](https://leetcode.com/problems/minimum-path-sum/description/)

Given a m x n grid filled with non-negative numbers, find a path from top left to bottom right, 
which minimizes the sum of all numbers along its path.

Note: You can only move either down or right at any point in time.

- Input: grid = [[1,3,1],[1,5,1],[4,2,1]]
- Output: 7
- Explanation: Because the path 1 → 3 → 1 → 1 → 1 minimizes the sum.

### Intuition
> [!IMPORTANT]
> We can reach (i, j) from either:
>
>           1. from (i-1, j)
>           2. from (i, j-1)
>
> State:
>
>           dp[i][j] = min path sum to reach at (i, j)
>
> Transition:
>
>           dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])

```cpp
int minPathSum(vector<vector<int>>& grid) {

    int n =  grid.size(), m = grid[0].size();
    vector<vector<int>> dp(n, vector<int>(m, INT_MAX));
    dp[0][0] = grid[0][0];

    for(int i=0; i<n; i++) {
        for(int j=0; j<m; j++) {
            if(i == 0 && j == 0) continue;

            if(i > 0)
                dp[i][j] = min(dp[i][j], grid[i][j] + dp[i-1][j]);
            if(j > 0)
                dp[i][j] = min(dp[i][j], grid[i][j] + dp[i][j-1]);
        }
    }

    return dp[n-1][m-1];
}
```

## 2. Triangle
[Leetcode link](https://leetcode.com/problems/triangle/description/)

Given a triangle array, return the minimum path sum from top to bottom.

For each step, you may move to an adjacent number of the row below. More formally, if you are on 
index i on the current row, you may move to either index i or index i + 1 on the next row.

Input: triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
Output: 11
Explanation: The triangle looks like:
```
                   2
                  3 4
                 6 5 7
                4 1 8 3
The minimum path sum from top to bottom is 2 + 3 + 5 + 1 = 11 (underlined above)
```

> [!IMPORTANT]
> We can reach at (i, j) 
>
>           1. from (i-1, j) , if triangle(i-1, j) exists
>           2. from (i-1, j-1), triangle(i-1, j-1) always exists
>
>           dp[i][j] = triangle[i][j] + min(dp[i-1][j], dp[i-1][j-1])
>
>           return min(dp[n-1][j]) ==> min of last row

```cpp
nt minimumTotal(vector<vector<int>>& triangle) {
    int n = triangle.size(), m = triangle[n-1].size();

    vector<vector<int>> dp(n, vector<int>(m, INT_MAX));
    dp[0][0] = triangle[0][0];

    for(int i=1; i<n; i++) {
        for(int j=0; j<=i; j++) {

            if(j < i)
                dp[i][j] = min(dp[i][j], triangle[i][j] + dp[i-1][j]);
            if(j > 0)
                dp[i][j] = min(dp[i][j], triangle[i][j] + dp[i-1][j-1]);

        }
    }
    
    int ans = INT_MAX;
    for(int j=0; j<m; j++)
        ans = min(ans, dp[n-1][j]);
    
    return ans;
}
```

## 3. Minimum Falling Path Sum
[Leetcode link](https://leetcode.com/problems/minimum-falling-path-sum/description/)

Given an n x n array of integers matrix, return the minimum sum of any falling path through matrix.

A falling path starts at any element in the first row and chooses the element in the next row that 
is either directly below or diagonally left/right. Specifically, the next element from position 
(row, col) will be (row + 1, col - 1), (row + 1, col), or (row + 1, col + 1).

- Input: matrix = [[2,1,3],[6,5,4],[7,8,9]]
- Output: 13
- Explaination, path = 1->5->7 or 1->4->8

> [!IMPORTANT]
> We can reach (i, j) either from:
>
>           1. (i-1, j)
>           2. (i-1, j-1)
>           3. (i-1, j+1)
>
>           dp[i][j] = matrix[i][j] + min(dp[i-1][j], dp[i-1][j-1], dp[i-1][j+1])
>
>           return min(dp[n-1][j]) ==> min of last row

```cpp
int minFallingPathSum(vector<vector<int>>& matrix) {
       
    int n = matrix.size();
    vector<vector<int>> dp(n, vector<int>(n, INT_MAX));

    for(int j=0; j<n; j++) dp[0][j] = matrix[0][j]; // initialize first row

    for(int i=1; i<n; i++) {
        for(int j=0; j<n; j++){

            if(i > 0) 
                dp[i][j] = min(dp[i][j], dp[i-1][j]);
            if(i > 0 && j > 0)
                dp[i][j] = min(dp[i][j], dp[i-1][j-1]);
            if(i > 0 && j < n-1)
                dp[i][j] = min(dp[i][j], dp[i-1][j+1]);
            
            dp[i][j] += matrix[i][j];
        }
    }

    int ans = INT_MAX;
    for(int j=0; j<n; j++)
        ans = min(ans, dp[n-1][j]);
    
    return ans;
}
```

## 4. Minimum Falling Path Sum II
[Leetcode link](https://leetcode.com/problems/minimum-falling-path-sum-ii/description/)

Given an n x n integer matrix grid, return the minimum sum of a falling path with non-zero shifts.

A falling path with non-zero shifts is a choice of exactly one element from each row of grid
 such that no two elements chosen in adjacent rows are in the same column.

- Input: grid = [[1,2,3],[4,5,6],[7,8,9]]
- Output: 13
- Explanation: 
        The possible falling paths are:
        [1,5,9], [1,5,7], [1,6,7], [1,6,8],
        [2,4,8], [2,4,9], [2,6,7], [2,6,8],
        [3,4,8], [3,4,9], [3,5,7], [3,5,9]
        The falling path with the smallest sum is [1,5,7], so the answer is 13.

### Intuition
> [!IMPORTANT]
> We can reach (i, j)
>
>           From every element from prev row (i-1, k) except j != k 
>
>           dp[i][j] = grid[i][j] + min(dp[i-1][k]) with k != j
>
>           this is O(n^3) solution
>
> We can solve it in O(n^2)
>
> We just need smallest and second smallest answer from prev row
>
>           dp[i][j] = grid[i][j] + min1: if(mincol != j)
>           dp[i][j] = grid[i][j] + min2: else

```cpp
int minFallingPathSum(vector<vector<int>>& grid) {
        int n = grid.size();
        vector<vector<int>> dp(n, vector<int>(n, INT_MAX));
        for(int j=0; j<n; j++) dp[0][j] = grid[0][j];

        for(int i=1; i<n; i++) {
            int min1 = INT_MAX, min2 = INT_MAX;
            int minCol = -1;

            for(int j=0; j<n; j++) { // find min1 and min2 form prev row
                if(dp[i-1][j] < min1) {
                    min2 = min1;
                    min1 = dp[i-1][j];
                    minCol = j;
                } else if(dp[i-1][j] < min2) {
                    min2 = dp[i-1][j];
                }
            }

            for(int j=0; j<n; j++) {
                if(minCol != j)
                    dp[i][j] = grid[i][j] + min1;
                else
                    dp[i][j] = grid[i][j] + min2;
            }
        }


        int ans = INT_MAX;
        for(int j=0; j<n; j++)
            ans = min(ans, dp[n-1][j]);
        
        return ans;
    }
```

# CASE 3: Grid DP + State Compression

## 1. Maximum Number of Points with Cost
[Leetcode link](https://leetcode.com/problems/maximum-number-of-points-with-cost/description/)

You are given an m x n integer matrix points (0-indexed). Starting with 0 points, you want to 
maximize the number of points you can get from the matrix.

picking cells at coordinates (r, c1) and (r + 1, c2) will subtract abs(c1 - c2) from your score.

- Input: points = [[1,2,3],[1,5,1],[3,1,1]]
- Output: 9
- Explanation:
    The blue cells denote the optimal cells to pick, which have coordinates (0, 2), (1, 1), and (2, 0).
    You add 3 + 5 + 3 = 11 to your score.
    However, you must subtract abs(2 - 1) + abs(1 - 0) = 2 from your score.
    Your final score is 11 - 2 = 9.

### Intuition
> [!IMPORTANT]
> From (r, j) we move to (r+1, k)
>
>               Score += points[r+1][k] + abs(j - k)
>
> State:
>
>           dp[i][j] = max score till (i, j)
>
> Transition:
>
>           dp[i][j] = points[i][j] + max(dp[i-1][k] + abs(j-k)) 
>
>           if j>=k
>           dp[i][j] = points[i][j] + max(dp[i-1][k] + (j - k))
>                    = points[i][j] + max(dp[i-1][k] - k) + j
>
>           if j < k
>           dp[i][j] = points[i][j] + max(dp[i-1][k] + (k - j))
>                    = points[i][j] + max(dp[i-1][k] + k) - j
>
> To find max(dp[i-1][k] - k) and max(dp[i-1][k] + k)
>
>           We need to go through entire row (i-1) but
>           Now the time complexity becomes O(n^3)
>
> We can preCompute max(dp[i-1][k] - k) and max(dp[i-1][k] + k)
>
> For a row (i-1):
>
>           left[k]  = max(left[k-1], dp[i-1][k] + k)
>           right[k] = max(right[k+1], dp[i-1][k] - k)
>
>           dp[i][j] = points[i][j] + max(left[j] - j, right[j] + j)

```cpp
long long maxPoints(vector<vector<int>>& points) {
        
    int n = points.size(), m = points[0].size();
    vector<vector<long long>> dp(n, vector<long long>(m, LLONG_MIN));

    for(int j=0; j<m; j++) dp[0][j] = points[0][j]; // filling first row

    for(int i=1; i<n; i++) {
        vector<long long> left(m, LLONG_MIN); // compute left
        left[0] = dp[i-1][0] + 0;
        for(int k=1; k<m; k++)
            left[k] = max(left[k-1], dp[i-1][k] + k);
        
        vector<long long> right(m, LLONG_MIN); // compute right
        right[m-1] = dp[i-1][m-1] - (m-1);
        for(int k=m-2; k>=0; k--)
            right[k] = max(right[k+1], dp[i-1][k] - k);
        
        for(int j=0; j<m; j++) {
            dp[i][j] = points[i][j] + max(left[j] - j, right[j] + j);
        }
    }

    long long ans = LLONG_MIN;
    for(int j=0; j<m; j++)
        ans = max(ans, dp[n-1][j]);
    
    return ans;
}
```

## 2. Maximum Non Negative Product in a Matrix
[Leetcode link](https://leetcode.com/problems/maximum-non-negative-product-in-a-matrix/description/)

You are given a m x n matrix grid. Initially, you are located at the top-left corner (0, 0), 
and in each step, you can only move right or down in the matrix.

Among all possible paths starting from the top-left corner (0, 0) and ending in the bottom-right 
corner (m - 1, n - 1), find the path with the maximum non-negative product. The product of a 
path is the product of all integers in the grid cells visited along the path.

- Input: grid = [[-1,-2,-3],[-2,-3,-3],[-3,-3,-2]]
- Output: -1
- Explanation: It is not possible to get non-negative product in the path from (0, 0) to (2, 2), so return -1.

- Input: grid = [[1,-2,1],[1,-2,1],[3,-4,1]]
- Output: 8
- Explanation: Maximum non-negative product is shown (1 * 1 * -2 * -4 * 1 = 8).

### Intuition
> [!IMPORTANT]
> A max positive product can be acheived two ways:
> 1. max positive * curr element
> 2. min negative * curr element
>
> state: dp[i][j] = {u, v}
>
>           where u = maximum product achieved at (i, j)
>                 v = minimum product achieved at (i, j)

```cpp
int maxProductPath(vector<vector<int>>& grid) {
    
    int mod = 1e9+7;
    int n = grid.size(), m = grid[0].size();
    vector<vector<vector<long>>> dp(n, vector<vector<long>>(m, {0, 0}));
    
    dp[0][0] = {grid[0][0], grid[0][0]};

    for(int j=1; j<m; j++) {        // first row
        long long val = grid[0][j] * dp[0][j-1][0];
        dp[0][j] = {val, val};
    }
    
    for(int i=1; i<n; i++) {        // first column
        long long val = grid[i][0] * dp[i-1][0][0];
        dp[i][0] = {val, val};
    }
    
    for(int i=1; i<n; i++) {
        for(int j=1; j<m; j++) {
            long long val = grid[i][j];

            vector<long long> cand = {
                val*dp[i-1][j][0],
                val*dp[i-1][j][1],
                val*dp[i][j-1][0],
                val*dp[i][j-1][1]
            };

            dp[i][j][0] = *max_element(cand.begin(), cand.end());
            dp[i][j][1] = *min_element(cand.begin(), cand.end());
        }
    }

    long long ans = dp[n-1][m-1][0];
    if(ans < 0) return -1;
    return ans%mod;
}
```

## 3. Number of Paths with Max Score
[Leetcode link](https://leetcode.com/problems/number-of-paths-with-max-score/description/)

You are given a square board of characters. You can move on the board starting at the bottom right 
square marked with the character 'S'.

You need to reach the top left square marked with the character 'E'. The rest of the squares are
labeled either with a numeric character 1, 2, ..., 9 or with an obstacle 'X'. In one move you can go 
up, left or up-left (diagonally) only if there is no obstacle there.

Return a list of two integers: the first integer is the maximum sum of numeric characters you can collect, 
and the second is the number of such paths that you can take to get that maximum sum, taken modulo 10^9 + 7.

In case there is no path, return [0, 0].

- Input: board = ["E23","2X2","12S"]
- Output: [7,1]

- Input: board = ["E12","1X1","21S"]
- Output: [4,2]

### Intuition
> [!IMPORTANT]
> Go from S to E or E to S max score will be same
>
> It is possible that from row i we are not able to go to row (i+1)
>
>               if row i has all X
>
> State:
>
>               sum[i][j] = max sum from (0, 0) to (i, j)
>               paths[i][j] = number of paths to arrive at (i, j) with max sum
>
> Transition:
> 
>               To reach (i, j) we can come from (i-1, j), (i, j-1), (i-1, j-1)
>
>               say we go to (x, y) from (i, j)
>               we can go to (x, y) only if sum(i, j) != 0
>
>               if (board[x][y] + sum[i][j] == sum[x][y])
>                   // we just found a new path with same max score
>                   paths[x][y] += paths[i][j]
>
>               if (board[x][y] + sum[i][j] > sum[x][y])
>                   // we just found a new path with max score
>                   sum[x][y] = board[x][y] + sum[i][j]
>                   paths[x][y] = paths[i][j]

```cpp
vector<int> pathsWithMaxScore(vector<string>& board) {
    int n = board.size();
    int mod = 1e9+7;
    vector<vector<int>> dir = {{1, 0}, {0, 1}, {1, 1}};

    vector<vector<int>> sum(n, vector<int>(n, 0));
    vector<vector<int>> paths(n, vector<int>(n, 0));

    sum[0][0] = 0;
    paths[0][0] = 1;

    for(int i=0; i<n; i++) {
        for(int j=0; j<n; j++) {
            if(board[i][j] == 'X') continue;
            if(board[i][j] != 'E' && sum[i][j] == 0) continue; // we cant reach (i, j)

            for(auto d : dir) {
                int x = i + d[0], y = j + d[1];
                if(x>=n || y>=n || board[x][y] == 'X') continue;

                int currSum = sum[i][j];
                if(board[x][y] != 'S') currSum += (board[x][y] - '0');

                if(currSum == sum[x][y]) {
                    paths[x][y] += paths[i][j];
                    paths[x][y] %= mod;
                } else if(currSum > sum[x][y]) {
                    sum[x][y] = currSum;
                    paths[x][y] = paths[i][j];
                }


            }
        }
    }

    return {sum[n-1][n-1], paths[n-1][n-1]};
}
```
