# CASE 1. Longest Increasing Subsequence

State:
> dp[i] = Length of LIS ending at i
>
> Best subsequence whose LAST element is nums[i]

Transition:
> For every previous index:
>
>           for(int j=0; j<i; j++){
>               if(nums[j] < nums[i])
>                   dp[i] = max(dp[i], dp[j] + 1);
>           }

## 1. Longest Increasing Subsequence
[Leetcode link](https://leetcode.com/problems/longest-increasing-subsequence/description/)

Given an integer array nums, return the length of the longest strictly increasing subsequence.

 
Input: 
- nums = [10,9,2,5,3,7,101,18]
Output: 
- 4
Explanation: 
- The longest increasing subsequence is [2,3,7,101], therefore the length is 4.

```cpp
int lengthOfLIS(vector<int>& nums) {
    // dp[i] = LIS ending at i
    int n = nums.size();
    vector<int> dp(n, 1);

    int ans = 1;
    for(int i=1; i<n; i++) {
        for(int j=0; j<i; j++) {
            if(nums[j] < nums[i]) {
                dp[i] = max(dp[i], dp[j]+1);
            }
        }
        
        if(ans < dp[i]) ans = dp[i];
    }

    return ans;
}
/*
    Time = O(n^2)
*/
```

### It can be done within O(n* logn)
```cpp
int lengthOfLIS(vector<int>& nums) {
    vector<int> tails;
    int ans = 1;

    for(int num : nums) {
        if(tails.size() == 0 || tails.back() < num) tails.push_back(num);
        else {
            auto it = lower_bound(tails.begin(), tails.end(), num);
            *it = num;
        }

        if(ans < tails.size())ans = tails.size();
    }

    return ans;
}
```
