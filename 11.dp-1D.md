# 1D DP

You process items left to right (or right to left), and the answer at position i depends on earlier positions.

So you define:
> dp[i] = best / count / valid answer considering first i elements
or
> dp[i] = answer ending exactly at i

1. Is the input linear?
2. Does answer at current index depend on previous indices?
3. Need one of these outputs?
    - max / min
    - count ways
    - possible / impossible
    - longest length

## 1. Climbing Stairs
[Leetcode link](https://leetcode.com/problems/climbing-stairs/description/)

Example 1:
    Input: n = 2
    Output: 2

    - Explanation: There are two ways to climb to the top.

    1. 1 step + 1 step
    2. 2 steps
    
Example 2:
    Input: n = 3
    Output: 3

    - Explanation: There are three ways to climb to the top.

    1. 1 step + 1 step + 1 step
    2. 1 step + 2 steps
    3. 2 steps + 1 step

> [!IMPORTANT]
> dp[i] = number of ways to climb at ith stair
>
> we can reach ith stair from (i-1) and (i-2) th stairs
> 
>               dp[i] = dp[i-1] + dp[i-2]

```cpp
int climbStairs(int n) {
    if(n < 2) return 1;

    vector<int> dp(n, 0); // number of ways to climb at ith stair
    dp[0] = 1;
    dp[1] = 2;

    for(int i=2; i<n; i++)
        dp[i] = dp[i-1] + dp[i-2];
    
    return dp[n-1];
}
```

## 2. Min Cost Climbing Stairs
You are given an integer array cost where cost[i] is the cost of ith step on a staircase. 
Once you pay the cost, you can either climb one or two steps.

> You can either start from the step with index 0, or the step with index 1.

> Return the minimum cost to reach the top of the floor.

Input: cost = [10,15,20]

Output: 15

Explanation: You will start at index 1.
- Pay 15 and climb two steps to reach the top.
- The total cost is 15.

### INTUITION
> [!IMPORTANT]
> dp[i] = minimum cost to reach ith stair
> 
> Since we need to reach at index n
> 
>               So create dp(n+1, 0)
>               dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])
>
>               We can jump from ith index then cost = dp[i] + cost[i]

```cpp
int minCostClimbingStairs(vector<int>& cost) {
    int n = cost.size();
    vector<int> dp(n+1, 0);
    dp[0] = 0;
    dp[1] = 0;

    for(int i=2; i<=n; i++) {
        dp[i] = min(
            dp[i-1] + cost[i-1],
            dp[i-2] + cost[i-2]
        );
    }

    return dp[n];
}
```

## 3. House Robber
[Leetcode link](https://leetcode.com/problems/house-robber/description/)

You can not rob two adjacent houses
> Given an integer array nums representing the amount of money of each house, 
> return the maximum amount of money you can rob tonight without alerting the police.

Input: nums = [2,7,9,3,1]

Output: 12

Explanation: 
Rob house 1 (money = 2), rob house 3 (money = 9) and rob house 5 (money = 1).
Total amount you can rob = 2 + 9 + 1 = 12.

### Intuition
> [!IMPORTANT]
> dp[i] = max money we can rob from houses [0...i]
>
> At a house 1 we have two choices, 
>   - rob it        = dp[i-2] + nums[i]
>   - don't rob it  = dp[i-1]
>
>           dp[i] = max(dp[i-1], dp[i-2] + nums[i])

```cpp
int rob(vector<int>& nums) {
    int n = nums.size();
    if(n == 1) return nums[0];

    vector<int> dp(n, 0);
    dp[0] = nums[0];
    dp[1] = max(nums[0], nums[1]);

    for(int i=2; i<n; i++) {
        dp[i] = max(dp[i-1], dp[i-2] + nums[i]);
    }

    return dp[n-1];
}
```

## 4. House Robber II
[Leetcode link](https://leetcode.com/problems/house-robber-ii/description/)

Houses are in circular manner

### Intuition
> [!IMPORTANT]
> Since houses are connected circularly
> - we can not rob 0th and (n-1)th house 
>
>                   if we rob 0th house then we can rob upto (n-2)th house
>                   If we rob 1st house then we can rob upto (n-1)th house
>       
>                   solve two times (0..n-2) and (1..n-1)
>                   return max(solve(0...n-2), solve(1...n-1)

```cpp
int rob(vector<int>& nums) {
    int n = nums.size();
    if(n == 1) return nums[0];
    if(n == 2) return max(nums[0], nums[1]);
    int ans = 0;

    // case 1: start from 0
    vector<int> dp(n, 0);
    dp[0] = nums[0];
    dp[1] = max(nums[0], nums[1]);

    for(int i=2; i<n-1; i++) {
        dp[i] = max(dp[i-1], dp[i-2] + nums[i]);
    }
    ans = max(ans, dp[n-2]);
    
    // case 2: start from 1
    dp.resize(n, 0);
    dp[1] = nums[1];
    dp[2] = max(nums[1], nums[2]);
    
    for(int i=3; i<n; i++) {
        dp[i] = max(dp[i-1], dp[i-2] + nums[i]);
    }
    ans = max(ans, dp[n-1]);

    return ans;
}
```
