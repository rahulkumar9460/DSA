# 1D DP

You process items left to right (or right to left), and the answer at position i depends on earlier positions.

So you define:
> dp[i] = best / count / valid answer considering first i elements
or
> dp[i] = answer ending exactly at i

1. Is the input linear?
2. Does answer at current index depend on previous indices?
3. Need one of these outputs?
    - max / min
    - count ways
    - possible / impossible
    - longest length

## 1. Climbing Stairs
[Leetcode link](https://leetcode.com/problems/climbing-stairs/description/)

Example 1:
    Input: n = 2
    Output: 2

    - Explanation: There are two ways to climb to the top.

    1. 1 step + 1 step
    2. 2 steps
    
Example 2:
    Input: n = 3
    Output: 3

    - Explanation: There are three ways to climb to the top.

    1. 1 step + 1 step + 1 step
    2. 1 step + 2 steps
    3. 2 steps + 1 step

> [!IMPORTANT]
> dp[i] = number of ways to climb at ith stair
>
> we can reach ith stair from (i-1) and (i-2) th stairs
> 
>               dp[i] = dp[i-1] + dp[i-2]

```cpp
int climbStairs(int n) {
    if(n < 2) return 1;

    vector<int> dp(n, 0); // number of ways to climb at ith stair
    dp[0] = 1;
    dp[1] = 2;

    for(int i=2; i<n; i++)
        dp[i] = dp[i-1] + dp[i-2];
    
    return dp[n-1];
}
```

## 2. Min Cost Climbing Stairs
You are given an integer array cost where cost[i] is the cost of ith step on a staircase. 
Once you pay the cost, you can either climb one or two steps.

> You can either start from the step with index 0, or the step with index 1.

> Return the minimum cost to reach the top of the floor.

Input: cost = [10,15,20]

Output: 15

Explanation: You will start at index 1.
- Pay 15 and climb two steps to reach the top.
- The total cost is 15.

### INTUITION
> [!IMPORTANT]
> dp[i] = minimum cost to reach ith stair
> 
> Since we need to reach at index n
> 
>               So create dp(n+1, 0)
>               dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])
>
>               We can jump from ith index then cost = dp[i] + cost[i]

```cpp
int minCostClimbingStairs(vector<int>& cost) {
    int n = cost.size();
    vector<int> dp(n+1, 0);
    dp[0] = 0;
    dp[1] = 0;

    for(int i=2; i<=n; i++) {
        dp[i] = min(
            dp[i-1] + cost[i-1],
            dp[i-2] + cost[i-2]
        );
    }

    return dp[n];
}
```

## 3. House Robber
[Leetcode link](https://leetcode.com/problems/house-robber/description/)

You can not rob two adjacent houses
> Given an integer array nums representing the amount of money of each house, 
> return the maximum amount of money you can rob tonight without alerting the police.

Input: nums = [2,7,9,3,1]

Output: 12

Explanation: 
Rob house 1 (money = 2), rob house 3 (money = 9) and rob house 5 (money = 1).
Total amount you can rob = 2 + 9 + 1 = 12.

### Intuition
> [!IMPORTANT]
> dp[i] = max money we can rob from houses [0...i]
>
> At a house 1 we have two choices, 
>   - rob it        = dp[i-2] + nums[i]
>   - don't rob it  = dp[i-1]
>
>           dp[i] = max(dp[i-1], dp[i-2] + nums[i])

```cpp
int rob(vector<int>& nums) {
    int n = nums.size();
    if(n == 1) return nums[0];

    vector<int> dp(n, 0);
    dp[0] = nums[0];
    dp[1] = max(nums[0], nums[1]);

    for(int i=2; i<n; i++) {
        dp[i] = max(dp[i-1], dp[i-2] + nums[i]);
    }

    return dp[n-1];
}
```

## 4. House Robber II
[Leetcode link](https://leetcode.com/problems/house-robber-ii/description/)

Houses are in circular manner

### Intuition
> [!IMPORTANT]
> Since houses are connected circularly
> - we can not rob 0th and (n-1)th house 
>
>                   if we rob 0th house then we can rob upto (n-2)th house
>                   If we rob 1st house then we can rob upto (n-1)th house
>       
>                   solve two times (0..n-2) and (1..n-1)
>                   return max(solve(0...n-2), solve(1...n-1)

```cpp
int rob(vector<int>& nums) {
    int n = nums.size();
    if(n == 1) return nums[0];
    if(n == 2) return max(nums[0], nums[1]);
    int ans = 0;

    // case 1: start from 0
    vector<int> dp(n, 0);
    dp[0] = nums[0];
    dp[1] = max(nums[0], nums[1]);

    for(int i=2; i<n-1; i++) {
        dp[i] = max(dp[i-1], dp[i-2] + nums[i]);
    }
    ans = max(ans, dp[n-2]);
    
    // case 2: start from 1
    dp.resize(n, 0);
    dp[1] = nums[1];
    dp[2] = max(nums[1], nums[2]);
    
    for(int i=3; i<n; i++) {
        dp[i] = max(dp[i-1], dp[i-2] + nums[i]);
    }
    ans = max(ans, dp[n-1]);

    return ans;
}
```

## 5. Decode Ways
[Leetcode link](https://leetcode.com/problems/decode-ways/description/)

For example, "11106" can be decoded into:

- "AAJF" with the grouping (1, 1, 10, 6)
- "KJF" with the grouping (11, 10, 6)

Input: s = "226"

Output: 3

Explanation:

"226" could be decoded as "BZ" (2 26), "VF" (22 6), or "BBF" (2 2 6).

### Intuition
> [!IMPORTANT]
> dp[i] = number of ways to decode string(0..i)
>               dp[i] += dp[i-1];    if s[i] != '0'  
>               dp[i] += dp[i-2];    if(s[i-2]s[i-1] is valid ie. 10...26)

```cpp
int numDecodings(string s) {
    if(s[0] == '0') return 0;

    int n = s.size();
    vector<int> dp(n, 0);
    dp[0] = 1;
    
    for(int i=1; i<n; i++) {
        if(s[i] != '0') dp[i] += dp[i-1];

        if(s[i-1] == '1' || (s[i-1] == '2' && s[i] <= '6')) {
            if(i-2 >= 0) dp[i] += dp[i-2];
            else dp[i] += 1;
        }
    }

    return dp[n-1];
}
```

## 6.  Perfect Squares
[Leetcode link](https://leetcode.com/problems/perfect-squares/description/)

> Given an integer n, return the least number of perfect square numbers that sum to n.

A perfect square is an integer that is the square of an integer; in other words, it is the 
product of some integer with itself. For example, 1, 4, 9, and 16 are perfect squares while 3 and 11 are not.

Example 1:
- Input: n = 12
- Output: 3
- Explanation: 12 = 4 + 4 + 4.

Example 2:
- Input: n = 13
- Output: 2
- Explanation: 13 = 4 + 9.

### Intuition
> [!IMPORTANT]
> dp[i] = least number of squares that sum to i
>
>                   squares = {1, 4, 9, 16, 25, 36, 49.......}
>                   for each sq : squares
>                       dp[i] = min(dp[i], 1+dp[i-sq])
>
>                   dp[i] = min(dp[i-1], dp[i-4], dp[i-9], dp[i-16]........)

```cpp
int numSquares(int n) {
    vector<int> dp(n+1, n); // initialize max values
    dp[0] = 0;

    for(int i=1; i<=n; i++) {
        for(int j=1; j*j<=i; j++) {
            int sq = j*j;

            dp[i] = min(dp[i], 1+dp[i-sq]);
        }
    }

    return dp[n];
}
```

## 7. Word Break
[Leetcode link](https://leetcode.com/problems/word-break/description/)

Given a string s and a dictionary of strings wordDict, 
>return true if s can be segmented into a space-separated sequence of one or more dictionary words.

Note that the same word in the dictionary may be reused multiple times in the segmentation.

 

Example 1:
- Input: s = "leetcode", wordDict = ["leet","code"]
- Output: true
- Explanation: Return true because "leetcode" can be segmented as "leet code".

### Intuition
> [!IMPORTANT]
> dp[i] = whether s[0...i] can be sengmented or not
>
>               To get dp[i]
>               for j=i-1 to 0
>                   if(dp[j] && s[j+1..i] exists) ==> dp[i] = true

```cpp
bool wordBreak(string s, vector<string>& wordDict) {
    unordered_set<string> words;
    for(string w: wordDict) words.insert(w);

    int n = s.size();
    vector<bool> dp(n, false);

    for(int i=1; i<n; i++) {
        if(words.count(s.substr(0, i+1))) dp[i] = true;

        for(int j=i-1; j>=0; j--) {
            if(dp[j] && words.count(s.substr(j+1, i-j))) {
                dp[i] = true;
                break;
            }
        }
    }

    return dp[n-1];
}
```

## 8. Longest Increasing Subsequence
Given an integer array nums, return the length of the longest strictly increasing subsequence.

- Input: nums = [10,9,2,5,3,7,101,18]
- Output: 4
- Explanation: The longest increasing subsequence is [2,3,7,101], therefore the length is 4

### Intuition
> [!IMPORTANT]
> dp[i] = max length of LCS that ends at i
>
>           For j = i-1 to 0
>               dp[i] = max(dp[i], 1+dp[j]) if nums[i] < nums[j]

```cpp
int lengthOfLIS(vector<int>& nums) {
    int n = nums.size();
    vector<int> dp(n, 1);
    int ans = 1;

    for(int i=1; i<n; i++) {
        for(int j=i-1; j>=0; j--) {
            if(nums[i] > nums[j])
                dp[i] = max(dp[i], 1 + dp[j]);
        }

        ans = max(ans, dp[i]);
    }

    return ans;
}
```

> [!NOTE]
> LIS can be solved with O(nlogn)
>
> tails[i] = minimum element where LIS of length (i+1) ends
>
> tails does NOT store the actual LIS
> - It stores the best possible tail for each LIS length
>
> Smaller tails are better because they maximize opportunities for future extensions.

```
 Example: arr = [3, 4, 5, 1, 2, 3, 4] Let's see why keeping 1 (the smallest value) helps:

            We use binary search to find the position where new element is to be inserted.

            First three elements: tails = [3, 4, 5] 
                3 is best tail for LIS of length 1
                4 is best tail for LIS of length 2
                5 is best tail for LIS of length 5

            arr[3] = 1 tails = [1, 4, 5]  // 1 replaces 3
            arr[4] = 2 tails = [1, 2, 5]  // 2 replaces 4 as it's smaller
            arr[5] = 3 tails = [1, 2, 3]  // 3 replaces 5
            arr[6] = 4 tails = [1, 2, 3, 4]  // 4 is appended as it's larger
```

```cpp
int lengthOfLIS(vector<int>& nums) {
    vector<int> tails;
    int ans = 1;

    for(int n: nums) {
        if(tails.size() == 0 || tails.back() < n) tails.push_back(n);

        else {
            int idx = lower_bound(tails.begin(), tails.end(), n) - tails.begin();
            tails[idx] = n;
        }

        if(tails.size() > ans) ans = tails.size();
    }

    return ans;
}
```

## 9. Minimum Cost For Tickets
[Leetcode link](https://leetcode.com/problems/minimum-cost-for-tickets/description/)

Train tickets are sold in three different ways:

- a 1-day pass is sold for costs[0] dollars,
- a 7-day pass is sold for costs[1] dollars, and
- a 30-day pass is sold for costs[2] dollars.
The passes allow that many days of consecutive travel.

> Return the minimum number of dollars you need to travel every day in the given list of days.

Input: days = [1,4,6,7,8,20], costs = [2,7,15]

Output: 11

Explanation: For example, here is one way to buy passes that lets you travel your travel plan:
- On day 3, you bought a 7-day pass for costs[1] = $7, which covered days 3, 4, ..., 9.
- On day 20, you bought a 1-day pass for costs[0] = $2, which covered day 20.
- In total, you spent $11 and covered all the days of your travel.

### Intuition
> [!IMPORTANT
> dp[i] = minimum travel cost to cover all travel up to day i
>
>            To cover travel on day i, the last ticket used could be:
>
>               1. a 1-day pass
>               2. a 7-day pass
>               3. a 30-day pass
>
>            Therefore:
>
>               dp[i] = min(
>                   dp[i-1] + costs[0],
>                   dp[i-7] + costs[1],
>                   dp[i-30] + costs[2]
>               )

```cpp
int mincostTickets(vector<int>& days, vector<int>& costs) {
    int n = days.size();
    int m = days[n-1];
    vector<int> dp(m+1, 0);

    unordered_set<int> travelDays;
    for(int d: days) travelDays.insert(d);

    for(int i=1; i<=m; i++) {
        int a = dp[i-1] + costs[0];
        int b = (i-7 >= 0) ? dp[i-7] + costs[1] : costs[1];
        int c = (i-30 >= 0) ? dp[i-30] + costs[2] : costs[2];

        if(travelDays.count(i)) dp[i] = min({a, b, c});
        else dp[i] = dp[i-1];
    }

    return dp[m];
}
```

## 10. Longest String Chain
[Leetcode link](https://leetcode.com/problems/longest-string-chain/description/)

Input: words = ["a","b","ba","bca","bda","bdca"]

Output: 4

Explanation: One of the longest word chains is ["a","ba","bda","bdca"].

### Intuition
> [!IMPORTANT]
> dp[i] = max length of chain ending at i
>
>               sort words with increasing size
>
>               dp[i]
>               for j = i-1 to 0
>                   dp[i] = max(dp[i], 1+dp[j]), if words[j] is predecessor of words[i]
>
>               return max of dp[0..n-1]

```cpp
bool compare(const string& a, const string &b) {
    return a.size() < b.size();
}


bool isPred(string a, string b) {
    if(b.size() != a.size()+1) return false;

    int i=0, j =0;
    bool skipped = false;
    while(i < a.size() && j < b.size()) {
        if(a[i] == b[j]) {
            i++;
            j++;
            continue;
        }

        if(!skipped) {
            j++;
            skipped = true;
        } else return false;
    }

    return true;
}

int longestStrChain(vector<string>& words) {
    int n = words.size();
    sort(words.begin(), words.end(), compare);

    vector<int> dp(n, 1);
    int ans = 1;

    for(int i=1; i<n; i++) {
        for(int j=i-1; j>=0; j--) {
            if(isPred(words[j], words[i]))
                dp[i] = max(dp[i], 1+dp[j]);
        }

        ans = max(ans, dp[i]);
    }

    return ans;
}
```
