# State Machine DP

You model the problem as:
> “At any point, what STATE am I in?”

Then:
> each action moves you to another state
> DP stores best answer for each state

Instead of:
> “try every possibility”

you think:
> “what are the valid states and transitions?”

- Used in stocks, cooldown, transactions.

## The Core Identification Trick

If the problem has:

1. sequential decisions
2. mutually exclusive modes
3. actions changing future permissions
4. cooldown/waiting/holding/etc.

## Generic Template


> dp[i][state] means:
> best answer at index/day i
> while being in state

Transition:

> dp[i][newState] =
>    max(dp[i][newState],
>        dp[i-1][oldState] + contribution)

> [!NOTE]
> State = smallest info needed to make future decisions.

## 1. Best Time to Buy and Sell Stock
[Leetcode link](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/description/)

You are given an array prices where prices[i] is the price of a given stock on the ith day.

You want to maximize your profit by choosing a single day to buy one stock and choosing a different day in the future to sell that stock.

> Return the maximum profit you can achieve from this transaction. If you cannot achieve any profit, return 0.

- Input: prices = [7,1,5,3,6,4]
- Output: 5
- Explanation: Buy on day 2 (price = 1) and sell on day 5 (price = 6), profit = 6-1 = 5.

### Intuition
> [!IMPORTANT]
> Lest have a concept of Hold and Not-Hold
>
> Each day can end with two STATES:
> 1. HOLD -> We have a stock -> meaning we alredy have a stock or we buy a new one
>
> 2. NOT-HOLD -> we dont have a stock --> meaning we never had or we just sold
>
> State transition:
> - HOLD:
>                   1. We can continue holding 
>                   2. Or we can buy with profit = -price[i]
>                   profit while holding: hold[i] = max(hold[i-1], -price[i])
>
> - NOT-HOLD:
>                   1. We can continue not holding
>                   2. Or we can sell with profit = price[i]
>                       But we can sell only IF: we were holding at (i-1) day
>                   profit while not-holding: not-Hold[i] = max(notHold[i-1], hold[i-1] + price[i])                    notHold[i] = max(notHold[i-1], hold[i-1]+price[i])

```cpp
int maxProfit(vector<int>& prices) {
    int hold = -prices[0]; // Hold: buy --> negative profit: since we bought
    int notHold = 0; // Not-Hold: Sell 

    for(int i=1; i<prices.size(); i++) {
        hold = max(hold, -prices[i]);

        notHold = max(notHold, hold+prices[i]);
    }

    return notHold;
}
```

## 2. Best Time to Buy and Sell Stock II
[Leetcode link](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-ii/description/)

On each day, you may decide to buy and/or sell the stock.
ensuring you never hold more than one share of the stock, you can buy or sell multiple times.

- you can buy a new share only after you sell the previous one.

Input: prices = [7,1,5,3,6,4]

Output: 7

Explanation: Buy on day 2 (price = 1) and sell on day 3 (price = 5), profit = 5-1 = 4.
Then buy on day 4 (price = 3) and sell on day 5 (price = 6), profit = 6-3 = 3.
- Total profit is 4 + 3 = 7.

### Intuition
> [!IMPORTANT]
> Each day can end with two STATES:
> 1. HOLD -> We have a stock -> meaning we alredy have a stock or we buy a new one
>
> 2. NOT-HOLD -> we dont have a stock --> meaning we never had or we just sold
>
> State transition:
> - HOLD:
>                   1. We can continue holding 
>                   2. Or we can buy with profit = -price[i]
>                       But we can buy only IF: we were at not-holding at (i-1) day
>                   profit while holding: hold[i] = max(hold[i-1], notHolding[i-1] - price[i])
>
> - NOT-HOLD:
>                   1. We can continue not holding
>                   2. Or we can sell with profit = price[i]
>                       But we can sell only IF: we were holding at (i-1) day
>                   profit while not-holding: not-Hold[i] = max(notHold[i-1], hold[i-1] + price[i])

```cpp
int maxProfit(vector<int>& prices) {
    int hold = -prices[0]; // max profit while holding
    int notHold = 0; // max profit while not holding

    for(int i=1; i<prices.size(); i++) {
        int newHold = max(hold, notHold-prices[i]);

        int newNotHold = max(notHold, hold+prices[i]);

        hold = newHold;
        notHold = newNotHold;
    }    

    return notHold;
}
```

## 3. Best Time to Buy and Sell Stock with Cooldown
[Leetcode link](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-with-cooldown/description/)

Now you have to wait one day before buying after selling a stock

- Input: prices = [1,2,3,0,2]
- Output: 3
- Explanation: transactions = [buy, sell, cooldown, buy, sell]

### Intuition
> [!IMPORTANT]
>
> State transition:
> - HOLD:
>                   1. We can continue holding 
>                   2. Or we can buy with profit = -price[i]
>                       But we can buy only IF: we were at not-holding at (i-2) day
>                                               Need to leave (i-1)th day for cooldown
>                   profit while holding: hold[i] = max(hold[i-1], notHolding[i-2] - price[i])
>
> - NOT-HOLD:
>                   1. We can continue not holding
>                   2. Or we can sell with profit = price[i]
>                       But we can sell only IF: we were holding at (i-1) day
>                   profit while not-holding: not-Hold[i] = max(notHold[i-1], hold[i-1] + price[i])

```cpp
int maxProfit(vector<int>& prices) {
    int n = prices.size();
    if(n < 2) return 0;

    vector<int> hold(n, INT_MIN);
    vector<int> notHold(n, 0);

    hold[0] = -prices[0];

    for(int i=1; i<n; i++) {
        if(i-2 < 0) hold[i] = max(hold[i-1], -prices[i]);
        else hold[i] = max(hold[i-1], notHold[i-2]-prices[i]);

        notHold[i] = max(notHold[i-1], hold[i-1]+prices[i]);
    }

    return notHold[n-1];
}
```

## 4. Best Time to Buy and Sell Stock with Transaction Fee
[Leetcode link](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-with-transaction-fee/description/)

You are given an array prices where prices[i] is the price of a given stock on the ith day, 
> and an integer fee representing a transaction fee.

Input: prices = [1,3,2,8,4,9], fee = 2

Output: 8

Explanation: The maximum profit can be achieved by:
- Buying at prices[0] = 1
- Selling at prices[3] = 8
- Buying at prices[4] = 4
- Selling at prices[5] = 9
> The total profit is ((8 - 1) - 2) + ((9 - 4) - 2) = 8.

### Intuition
> [!IMPORTANT]
> State transition:
> - HOLD:
>                   1. We can continue holding 
>                   2. Or we can buy with profit = -price[i] - fee
>                       But we can buy only IF: we were at not-holding at (i-1) day
>                   profit while holding: hold[i] = max(hold[i-1], notHolding[i-1] - price[i] - fee)
>
> - NOT-HOLD:
>                   1. We can continue not holding
>                   2. Or we can sell with profit = price[i]
>                       But we can sell only IF: we were holding at (i-1) day
>                   profit while not-holding: not-Hold[i] = max(notHold[i-1], hold[i-1] + price[i])
>
> - Above we paid fee at buy time
> - We can pay fee at sell time: it wont make result change
> - Alternate state transition:
>
>                   hold[i] = max(hold[i-1], notHolding[i-1] - price[i])
>                   not-Hold[i] = max(notHold[i-1], hold[i-1] + price[i] - fee)

```cpp
int maxProfit(vector<int>& prices, int fee) {
    int hold = -prices[0] - fee;
    int notHold = 0;

    for(int i=1; i<prices.size(); i++) {
        int newHold = max(hold, notHold-prices[i]-fee);
        int newNotHold = max(notHold, hold+prices[i]);

        hold = newHold;
        notHold = newNotHold;
    }

    return notHold;
}
```

## 5. Best Time to Buy and Sell Stock IV
You are given an integer array prices where prices[i] is the price of a given stock on the ith day, and an integer k.

Find the maximum profit you can achieve. You may complete at most k transactions: i.e. you may buy at most k times and sell at most k times.

Input: k = 2, prices = [3,2,6,5,0,3]

Output: 7

Explanation: 
> Buy on day 2 (price = 2) and sell on day 3 (price = 6), profit = 6-2 = 4.
> Then buy on day 5 (price = 0) and sell on day 6 (price = 3), profit = 3-0 = 3.

### Intuition
> [!IMPORTANT]
> State transition:
> 
>                   hold[i][j]    = max profit at day i while holding with completing j transcations
>                   notHold[i][j] = max profit at day i while not holding with completing j transcations 
>
>                   A transcation is compeleted only after a stock is sold
>                   Buying does not increase number of transcations but selling does
>
>
> - HOLD:
>                   1. We can continue holding 
>                   2. Or we can buy with profit = -price[i]
>                       But we can buy only IF: we were at not-holding at (i-1) day completing (j) transcations
>                   profit while holding: 
>                           hold[i][j] = max(hold[i-1][j], notHolding[i-1][j] - price[i])
>
> - NOT-HOLD:
>                   1. We can continue not holding
>                   2. Or we can sell with profit = price[i]
>                       But we can sell only IF: we were holding at (i-1) day with completing (j-1) transcations
>                   profit while not-holding: 
>                           not-Hold[i][j] = max(notHold[i-1][j], hold[i-1][j-1] + price[i])

```cpp
int maxProfit(int k, vector<int>& prices) {
    int n = prices.size();

    vector<vector<int>> hold(n, vector<int>(k+1, INT_MIN));
    vector<vector<int>> notHold(n, vector<int>(k+1, 0));

    hold[0][0] = -prices[0];

    for(int i=1; i<n; i++) {
        for(int j=0; j<=k; j++) {
            hold[i][j] = max(hold[i-1][j], notHold[i-1][j] - prices[i]);

            if(j > 0)
                notHold[i][j] = max(notHold[i-1][j], hold[i-1][j-1] + prices[i]);
        }
    }

    int ans = 0;
    for(int j=0; j<=k; j++) {
        ans = max(ans, notHold[n-1][j]);
    }

    return ans;
}
```
