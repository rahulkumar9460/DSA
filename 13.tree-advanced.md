# SEGMENT TREE

arr = [1, 3, 5, 7]

## BUILD

```
Segment Tree:
                16
              /    \
             4      12
           /  \    /  \
          1    3  5    7
```

16 = sum[0, 3]
4  = sum[0, 1]
12 = sum[2, 3]
1  = sum[0, 0]
3  = sum[1, 1]
5  = sum[2, 2]
6  = sum[3, 3]

> [!IMPORTANT]
>               Segment tree represented as tree:
>                     16, 4, 12, 1, 3, 5, 7
>               idx =  0, 1,  2, 3, 4, 5, 6
>
>               for idx, its left node will be at  = idx*2 + 1
>               for idx, its right node will be at = idx*2 + 2 

Why we represent tree as an array?
Because:

1. arrays are fast
2. no pointer tree needed
3. memory cache friendly
4. easier implementation

```cpp
void build(int idx, int low, int high, vector<int>&arr) {
    //build segment tree node at idx for given arr[low....high]

     // node has single element --> leaf node
    if(low == high) {
        seg[idx] = arr[low];
        return;
    }

    int mid = (low + high)/2;

    // build left segment tree
    build(idx*2 + 1, low, mid, arr);

    // build right segment tree
    build(idx*2 + 2, mid+1, high, arr);

    seg[idx] = seg[idx*2 + 1] + seg[idx*2 + 2];
}
// O(n)
```

## QUERY

```
                [0,3] = 16
               /             \
        [0,1] = 4          [2,3] = 12
         /      \           /       \
 [0,0]=1   [1,1]=3   [2,2]=5   [3,3]=7
```

query[1, 2] ==> give sum of range arr[1..2]

> [!IMPORTANT]
>
>                For a query ask: "Does this segment contribute to my answer?"
>
> A segment can contribute in three manners: 
>
> There are three cases
> - case 1: No overlap: Segment outside query
>
>               segment tree node = [0, 0] and query = [1, 2]
>               no common element, segment node doesn't contribute, so contribution = 0;
>
> - case 2: Complete overlap: Segment inside query
>
>               segment tree node = [2, 2] and query = [1, 2]
>               complete segment node contributes: so contribution = 5
>
> - case 3: Partial overlap:
>
>               segment tree node = [0, 3] and query = [1, 2]
>               segment node contains sum from 0 to 3 = 16, we cant not return it
>                   So we need to split it:
>                   1. node = [0, 1] and query = [1, 2]
>                   2. node = [2, 3] and query = [1, 2] 


Lets take one example:
```
query[1, 2] ==> get sum from index 1 to 2

- Start from root node of segment tree which is [0, 3]
    partial overlap: split it: [0, 1] and [2, 3]

    - seg[0, 1] and query[1, 2]
        partial overlap: split it: [0, 0] and [1, 1]
        
        - seg[0, 0] and query[1, 2]
            no overlap: contribution = 0
        
        - seg[1, 1] and query[1, 2]
            complete overlap: entire segment contributes = 3
        
    - seg[2, 3] and query[1, 2]
        partial overlap: split it: [2, 2] and [3, 3]

        - seg[2, 2] and query[1, 2]
            complete overlap: entire segment contributes = 5
        
        - seg[3, 3] and query[1, 2]
            no overlap: contribution = 0


Total contribution = 0 + 3 + 5 + 0 = 8
```

```cpp
int query(int idx, int low, int high, int ql, int qr) {
    // query = [ql, qr]
    // idx = segment tree index
    // segment node at idx covers = [low, high]

    // no overlap, segment outside query
    if(high < ql  || low > qr )
        return 0;

    // complete overlap, segment inside query
    if(low >= ql && high <= qr)
        return seg[idx];

    int mid = (low + high)/2;
    
    int left  = query(idx*2+1, low, mid, ql ,qr);
    int right = query(idx*2+2, mid+1, high, ql, qr);

    // partial overlap
    return left + right;
}

// O(log(n))
```

## UPDATE

```
                [0,3] = 16
               /             \
        [0,1] = 4          [2,3] = 12
         /      \           /       \
 [0,0]=1   [1,1]=3   [2,2]=5   [3,3]=7
```

> Update arr[2] = 10

> Segments that contain 2 will be affected:

- [0, 3], [2, 3] and [2, 2]         are affected
- [0, 1], [0, 0], [1, 1], [3, 3]    are not affected

> [!IMPORTANT]
>
>               "Does this segment contain index i?"
>
> Recursion idea
>
> - suppose update index 2
> - we start from [0, 3]
> - mid is 1 so check where is 2?, left = [0, 1] or right = [2, 3]
> - 2 is in right, so only update right
>
>       - Now node is [2, 3], mid = 2
>       - left = [2, 2] and right = [3, 3]
>       - 2 is in left, so update only left
>
>           - Now node is [2, 2], leaf node reached
>           - update the value seg[idx] = 10
>
>                   While Recursion retruns: Recalculate the parent's value
>                   For example: seg[2, 3] = 12 but now it is = 10+7   = 17
>                                                   now root [0, 3] is = 4+17 = 21


```cpp
void update(int idx, int low, int high, int i, int value) {
    // leaf node
    if(low == high) {
        seg[idx] = value;
        return;
    }

    int mid = (low+high)/2;

    // if i is in left part
    if(i <= mid) update(idx*2+1, low, mid, i, value);

    // else i is in right part
    else update(idx*2+2, mid+1, high, i, value);

    // recalculate parent
    seg[idx] = seg[idx*2+1] + seg[idx*2+2];
}

// O(log(n))
```

## 1. Range Sum Query - Mutable
[Leetcode link](https://leetcode.com/problems/range-sum-query-mutable/description/)

Given an integer array nums, handle multiple queries of the following types:

1. Update the value of an element in nums.
2. Calculate the sum of the elements of nums between indices left and right inclusive where left <= right.

```cpp
class SegmentTree {
    vector<int> seg;
public:
    SegmentTree(int n) {
        seg.resize(4*n, 0);
    }

    void build(int idx, int low, int high, vector<int>&arr) {
        if(low == high) {
            seg[idx] = arr[low];
            return;
        }

        int mid = (low+high)/2;

        build(idx*2+1, low, mid, arr);
        build(idx*2+2, mid+1, high, arr);

        seg[idx] = seg[idx*2+1] + seg[idx*2+2];
    }

    int query(int idx, int low, int high, int ql, int qr) {
        // no overlap
        if(high < ql || low > qr) return 0;

        // complete ovelap; segment inside query
        if(low >= ql && high <= qr) return seg[idx];

        int mid = (low+high)/2;
        int left = query(idx*2+1, low, mid, ql, qr);
        int right = query(idx*2+2, mid+1, high, ql, qr);

        return left + right;
    }

    void update(int idx, int low, int high, int i, int value) {
        if(low == high) {
            seg[idx] = value;
            return;
        }

        int mid = (low+high)/2;
        if(i <= mid) update(idx*2+1, low, mid, i, value);
        else update(idx*2+2, mid+1, high, i, value);

        seg[idx] = seg[idx*2+1] + seg[idx*2+2];
    }
};

class NumArray {
    SegmentTree sgt;
    int n;
public:
    NumArray(vector<int>& nums) : sgt(nums.size()) {
        this->n = nums.size();
        sgt.build(0, 0, n-1, nums);
    }
    
    void update(int index, int val) {
        sgt.update(0, 0, n-1, index, val);
    }
    
    int sumRange(int left, int right) {
        return sgt.query(0, 0, n-1, left, right);
    }
};
```

class MinSegmentTree {

        else update(idx*2+2, mid+1, high, i, value);

        seg[idx] = min(seg[idx*2+1], seg[idx*2+2]);

# Lazy Propagation

> current update
>
> we only update one index arr[4] = 10 

> [!IMPORTANT]
> Suppose we need to: Add +3 to every element from [2,7]
> 
>               for(i=2; i<=7; i++)
>                   update(...)
>
>               If we do update for 2 <= i <= 7 ==> it takes (high-low+1) * log(n) time complexity
>                   which is O(nlog(n)

```
Lazy Propagation Idea

Instead of updating immediately
    - postpone the updates for later
    - apply only when needed
```

> [!NOTE]
> Main idea befind lazy propogation is:
>           
>           Instead of updating children immediately
>           Update this segment when needed
>
>           To minimise the work in case of range-updates (ex. add +3 for range [3, 9])

## Most important intuition
```
arr = [1,3,5,7] 

                [0,3] = 16
              /               \
        [0,1]=4            [2,3]=12

update: add +10 for range[0, 3]

Do we REALLY need to go to all leaf nodes? ----- NO
```

> [!IMPORTANT]
> Instead of going deeper:
> - just update root directly.
>
>                   old = 16
>                   new = 16 + 4*10 = 56
>                       why 4*10, because segment length is 4 = (3-0+1)
>
>                   But now children has outdated value
>                   So we need to mark this node [0, 3] has pending children
>                       like: lazy[idx]
>
>                   lazy array stores pending updates
>
>                    suppose: update [0,3] by +10
>                    We do: seg[root] = 56
>                    And mark:
>                           lazy[left child]  += 10
>                           lazy[right child] += 10
>                   meaning: children still need +10 later
>
> - WHAT DOES LAZY ARRAY MEAN?
>                   suppose: lazy[5] = 7
>                   it means:
>                       "Before using node 5,
>                       apply pending +7 update."
>
> - WHEN DO WE PUSH LAZY?
>                   Whenever we visit a node
>                       1. for query
>                       2. for update
>                               First: resolve pending lazy update: push(idx, low, high)
>                               push() --> applies lazy changes to node at idx and its children node and remove lazy at idx


```cpp
void push(int idx, int low, int high) {
    // no pending update
    if(lazy[idx] == 0)
        return;

    // apply pending update
    seg[idx] += (high - low + 1) * lazy[idx];

    // if it has children
    if(low != high) {
        lazy[2*idx+1] += lazy[idx];
        lazy[2*idx+2] += lazy[idx];
    }

    // clear lazy
    lazy[idx] = 0;
}

void rangeUpdate(int idx, int low, int high, int rl, int rr, int val) {
    // update for range [rl, rr] with val
    // resolve pending updates
    push(idx, low, high);

    // no overlap
    if(high < rl || low > rr)
        return;

    // complete overlap
    if(low >= rl && high <= rr) {
        seg[idx] += (high-low+1) * val; // update root node

        if(low != high) {
            // mark children node with pending update
            lazy[2*idx+1] += val;
            lazy[2*idx+2] += val;
        }

        return;
    }

    // partial overlap
    int mid = (low + high) / 2;
    rangeUpdate(2*idx+1, low, mid, rl, rr, val);
    rangeUpdate(2*idx+2,  mid+1, high, rl, rr, val);

    seg[idx] = seg[2*idx+1] + seg[2*idx+2];
}

int query(int idx, int low, int high, int ql, int qr) {
    push(idx, low, high);

    // no overlap
    if(high < ql || low > qr)
        return 0;

    // complete overlap
    if(low >= ql && high <= qr) return seg[idx];

    int mid = (low + high) / 2;
    int left = query(2*idx+1, low, mid, ql, qr);
    int right = query(2*idx+2, mid+1, high, l, r);

    return left + right;
}
```
